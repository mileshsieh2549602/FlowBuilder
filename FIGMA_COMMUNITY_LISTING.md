# Flow Builder for Figma - Community Listing Draft

## English Listing

### Name
Flow Builder for Figma

### Short Description
Draw stable orthogonal connectors between two frames with selection-order direction control.

### Full Description
Flow Builder helps teams create connector lines between screens quickly and reliably.

v1.0 is intentionally connector-focused:

- Select exactly 2 frames (or image-filled layers)
- Click **Generate Connector**
- Connector direction follows selection order (source -> target)
- Orthogonal path rendering for clean flow diagrams
- Connectors stay attached when frames move/resize
- Optional debug markers for endpoint/path diagnostics

Built for UI/UX flow mapping with a simple, stable workflow.

### Suggested Tags
connector, flow, user-flow, ux, wireframe, diagram, arrows, prototyping

### 完整描述
