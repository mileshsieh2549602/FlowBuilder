# Flow Builder for Figma - Community Listing Draft (v1.1)

## English Listing

### Name
Flow Builder for Figma

### Short Description
Auto-generate stable flow connectors and edit node types fast for Wireframe/User/UI Flow work.

### Full Description
Flow Builder helps UI/UX teams create and maintain flow diagrams with less repetitive manual work.

v1.1 highlights:

- Auto-generate connector when exactly 2 Frame/Image nodes are selected
- Direction follows selection order (source -> target)
- Stable orthogonal connector rendering that stays attached while frames move/resize
- Node Type panel for fast conversion:
  - None Node
  - Process (diamond, 180x180)
  - Start/End (pill-style rounded rectangle)
  - Y/N (fixed 52x52 format)
- Text-preserving node type switches for None/Process/Start-End
- Simplified plugin panel focused on Node Type controls

Built for Wireframe Flow, User Flow, and UI Flow mapping inside real product design files.
